VLSM (Variable Length Subnet Mask)

Design the network of MVP Group of Companies with the following:
Meralco.com = 1200 employees
smart.com.ph = 900 employees
Tv5.net = 500 employees
pldt.com.ph = 2200 employees


!C2-S2 (pldt.com.ph = 2200 employees)

To solve this question... we use Rivan's CSI Method

C = Convert it - 2200= 12bits
S = Subract it -  /32 - /12 = /20 (3rd, 16i) 
I = Ipasok sa Hiwa - Ipasok sa 3rd si 16i = 255.255.240.0

PLDT Net: 10.100.16.0/20
F 10.100.16.1/20
L 10.100.31.254/20
B: 10.100.31.255/20


!C2
config t
vlan 2004
 name pldt.com
 exit
Int vlan 2004
no shut
ip add 10.100.16.1 255.255.240.0
ip dhcp excluded-add 10.100.16.1 10.100.16.20
ip dhcp pool pldt.com
 network 10.100.16.0 255.255.240.0
 default-router 10.100.16.1

 Int e1/0
  swi access vlan 2004
  end

!S2
conf t
 int e1/0
 ip add dhcp
 shut
 no shut 
 end
