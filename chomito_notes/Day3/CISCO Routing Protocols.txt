CISCO Routing Protocols

To be a master to routing, know "IM BODSS"

I - IS-IS (CCIE Level)
M - MPLS (Multi Protocol Layer Switching) (CCNP Level)
+++++++++++++++++++++++++++++++++++++++
B - BGP (Border Gateway Protocol) (CCNP Level, but preferable with exp. on CCNA)
O - OSPF (Open Shortest Path First)
D - EIGRP (Enhanced Interior Gateway Protocol)
-
S - Static Route
S* - Default Static (Stub Routing)



Best practice in routing, the two rules of pingables.
1. PING = DIKIT (Direct Connection)
2. ROUTE = NOT DIKIT



STATIC ROUTING
- Admin Distance is 2
- Also known as Manual Routing
- Applying static routes requires 2-way configuration
- Works on all systems


recipe: ip route <not directly conneted network IP>
		 <subnet mask of NDCN (not directly connected network)>
		 <Host IP of next hop>

@R4--->R2
conf t
 ip route 10.1.1.4 255.255.255.252 10.1.1.9
 !(10.1.1.4 is netIP for 10.1.1.5 and 10.1.1.6)
 end


@R2--->R4
conf t
 ip route 10.1.1.8 255.255.255.252 10.1.1.6
 !(10.1.1.6 is netIP for 10.1.1.9 and 10.1.1.10)
 end

 end

!EIGRP Routing

EIGRP
- The best dynamic routing protocol
- Cisco Proprietary
- Administrative Distance is 90
- Same AS number to other routers advertises


EIGRP recipe:
 router eigrp ## (Autonomous System No.)
  no auto-summary
  network <directly connected netIP(network IP)> <wildcard mask of DCN*>			
						  *optional


@C1
conf t
 router eigrp 100
 no auto-summary
 network 10.1.4.4 0.0.0.3
 network 10.2.1.0 0.0.0.255
 network 10.2.2.0 0.0.0.255
 network 192.168.1.128 0.0.0.31
end


@C2
conf t
 router eigrp 100
 no auto-summary
 network 10.1.4.8 0.0.0.3
 network 10.2.1.0 0.0.0.255
 network 10.2.2.0 0.0.0.255
 network 192.168.1.128 0.0.0.31
end


@R4

DCN - Directly Connected Network

OSPF Routing (Open Shortest Path First)
- Multi-Vendor Dynamic Routing
- Implements Dijkstra Algorithm
- Administrative Distance of 110
- Advertise by AREA (Area 0 is the backbone)


recipe:
router ospf # <Process ID>
router-id <ip, mostly loopback>
 network <DCN> <wildcard DCN> Area #

OSPF State: DOWN > INT > TWO-WAY > EX START > EXCHANGE > LOADING > FULL

OSPF ROUTER ROLES ELECTION:
DR - Designated Router (master router)
BDR - Backup Designaed Router
- (None or DROther) - Router without special administrative duty

ABR - Area Boundary Router
ASBR - Autonomous System boundary Router

OSPF LSA (Link State Advertisement Types)
Type 1 (Router LSA) - Advertising the "O"
Type 2 (Network LSA) - Advertised by DR
Type 3 (Summary LSA) - Advertising the "O IA" (OSPF Inter Area)
Type 4 (ASBR Summary LSA) - Metric 
Type 5 (AS External LSA) - Advertising "O E2"

BGP ROUTING
- Mostly used for WAN
- Using Autonomous System Number
- Used by ISP and Large Corporations
- BiGPayroll


BGP States: Notification, Open, Keep-Alive, Update




recipe:
 router bgp # <AS no.>
 bgp log-neighbor-changes
 neighbor <direct IP of next peer> remote-as # <AS no. of neighbor>
 network <netIP between this host and neighbor> mask <Subnet Mask of neighbor>
end



@R1
conf t
 router bgp 1
 bgp log-neighbor-changes
 neighbor 208.8.8.4 remote-as 45
 neighbor 207.7.7.2 remote-as 2
 neighbor 209.9.9.3 remote-as 3
 network 208.8.8.0 mask 255.255.255.0
 network 207.7.7.0 mask 255.255.255.0
 network 209.9.9.0 mask 255.255.255.0
 network 210.1.1.0 mask 255.255.255.252
end
